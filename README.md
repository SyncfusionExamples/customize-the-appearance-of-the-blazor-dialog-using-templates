# Customize the Appearance of the Blazor Dialog Using Templates

This sample explains about how to customize a Syncfusion Blazor Dialog using templates in a Blazor WebAssembly app targeting .NET 10.

**Example**: https://blazor.syncfusion.com/demos/dialog/template

**Documentation**: https://blazor.syncfusion.com/documentation/dialog/template

## Prerequisites

* .NET 10 SDK
* Visual Studio 2022 or later

## How to run the project

* Checkout this project to a location in your disk.
* Open the project using Visual Studio or Visual Studio Code.
* Restore the NuGet packages by rebuilding the project.
* Run the project.
